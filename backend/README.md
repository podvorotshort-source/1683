# Онлайн-бронь → рабочий чат Telegram

Как это работает: гость заполняет форму на сайте → заявка уходит в Google Apps Script
(`apps-script/Code.gs`) → скрипт проверяет её и отправляет сообщение в рабочий чат от имени бота.

Токен бота хранится только в настройках скрипта Google и **никогда** не попадает в код сайта.

Настройка занимает ~10 минут, делается один раз.

## 1. Создать бота

1. В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot`.
2. Имя, например: `Город 1683 — бронь`. Юзернейм должен заканчиваться на `bot`, например `gorod1683_booking_bot`.
3. BotFather пришлёт **токен** вида `123456789:AA...`. Никому его не пересылайте.

## 2. Добавить бота в рабочий чат

1. Откройте рабочий чат администраторов → «Добавить участника» → найдите бота по юзернейму.
2. Напишите в чат команду `/start@имя_вашего_бота` — это нужно, чтобы скрипт узнал ID чата.

## 3. Создать скрипт

1. Откройте [script.google.com](https://script.google.com) → «Новый проект».
2. Назовите проект `Город 1683 — бронь`.
3. Удалите всё в файле `Код.gs` и вставьте содержимое `apps-script/Code.gs` из этого репозитория. Сохраните (Ctrl+S).

## 4. Вставить токен

1. Слева шестерёнка «Настройки проекта» → внизу «Свойства скрипта» → «Добавить свойство».
2. Свойство `TELEGRAM_BOT_TOKEN`, значение — токен из шага 1. Сохранить.

## 5. Узнать ID чата

1. Вернитесь в редактор (`<>` слева), вверху в списке функций выберите `findChatId` → «Выполнить».
2. Google попросит разрешения: «Проверить разрешения» → ваш аккаунт → «Дополнительные настройки» →
   «Перейти на страницу проекта» → «Разрешить». (Предупреждение появляется, потому что скрипт ваш личный, а не из магазина.)
3. Внизу в «Журнале выполнения» будет строка `TELEGRAM_CHAT_ID = -100...`.
4. Добавьте в «Свойства скрипта» второе свойство `TELEGRAM_CHAT_ID` с этим числом (вместе с минусом).

## 6. Проверить

Выберите функцию `sendTestBooking` → «Выполнить». В рабочем чате должно появиться тестовое сообщение о брони.

## 7. Опубликовать

1. Вверху справа «Начать развертывание» → «Новое развертывание».
2. Шестерёнка «Выберите тип» → «Веб-приложение».
3. «Запуск от имени»: **Я**. «У кого есть доступ»: **Все**.
4. «Начать развертывание» → скопируйте **URL веб-приложения** (заканчивается на `/exec`).

Этот URL не секретный — его нужно вписать в `js/main.js` в поле `bookingEndpoint` (в самом начале файла).
Пока поле пустое, заявка с сайта, как и раньше, открывается в WhatsApp.

## Если что-то поменяли в Code.gs

«Начать развертывание» → «Управление развертываниями» → карандаш → Версия: «Новая версия» → «Развернуть».
URL при этом не меняется.

## Защита от спама

- скрытое поле-ловушка и проверка «форма заполнена быстрее 3 секунд» отсекают ботов;
- с одного номера — не чаще одной заявки в 2 минуты;
- со всего сайта — не больше 30 заявок за 10 минут.

Если Telegram или Google недоступны, сайт покажет ошибку и предложит отправить ту же заявку в WhatsApp
или позвонить — гость не потеряется.

Если токен утёк: в @BotFather → `/revoke` → выберите бота, затем вставьте новый токен в «Свойства скрипта».
